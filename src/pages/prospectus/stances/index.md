# Basic Stances — Dachi-Kata

Stances form the structural foundation of all Shito-Ryu technique. Correct stance provides stability, power generation, and efficient weight transfer. Each stance has specific foot placement, knee bend, and weight distribution requirements.

## Stance Reference

| Japanese Name | English Name | Description |
|---|---|---|
| [Heisoku Dachi](/prospectus/stances/heisoku) | Closed Foot Stance | Toes & heels together — the "attention" stance. |
| [Musubi Dachi](/prospectus/stances/musubi) | Open Foot Stance | Heels together, toes apart — "knot" shape. |
| [Heiko Dachi](/prospectus/stances/heiko) | Parallel Stance | Feet apart, parallel (open, hip width). |
| [Hachiji Dachi](/prospectus/stances/hachiji) | Natural Stance | Feet apart, toes pointing OUT at 45 degrees (open, shoulder width). |
| [Uchi-Hachiji Dachi](/prospectus/stances/uchi-hachiji) | Inverted Natural Stance | Feet apart, toes pointing IN at 45 degrees (open, shoulder width). Also called *Niafanchi Dachi*. |
| [Shiko Dachi](/prospectus/stances/shiko) | Straddle Stance | Straddle leg — the "Sumo" stance. |
| [Moto Dachi](/prospectus/stances/moto) | Basic Forward Stance | Front knee partially bent, shorter forward stance (shorter than Zenkutsu Dachi). |
| [Zenkutsu Dachi](/prospectus/stances/zenkutsu) | Long Forward Stance | Front knee bent, long forward stance. |
| [Nekoashi Dachi](/prospectus/stances/nekoashi) | Cat Foot Stance | "Cat foot" stance — weight predominantly on rear foot. |
| [Sanchin Dachi](/prospectus/stances/sanchin) | Hourglass Stance | Inward tension stance ("hourglass" stance). |
| [Kokutsu Dachi](/prospectus/stances/kokutsu) | Back Stance | "Looking back" stance — weight predominantly on rear foot. |
| [Renoji Dachi](/prospectus/stances/renoji) | L-Shape Stance | Stance resembling the letter "L". |
| [Tee-Ji Dachi](/prospectus/stances/tee-ji) | T-Shape Stance | Stance resembling the letter "T" inverted. |
| [Kosa Dachi](/prospectus/stances/kosa) | Hooked Leg Stance | "Hooked leg" stance — legs crossed. |
| [Sagiashi Dachi](/prospectus/stances/sagiashi) | Heron Foot Stance | "Heron foot" stance — one-legged balance. |
| [Ukiashi Dachi](/prospectus/stances/ukiashi) | Floating Foot Stance | Similar to Nekoashi Dachi but more upright with a loose floating leg. |
