# মৌলিক স্ট্যান্সসমূহ — Dachi-Kata

স্ট্যান্স হলো শীতো-রিউ কারাতের সমস্ত কৌশলের কাঠামোগত ভিত্তি। সঠিক স্ট্যান্স শরীরের স্থায়িত্ব, শক্তি উৎপাদন এবং দক্ষতার সাথে শরীরের ওজন স্থানান্তরে সাহায্য করে। প্রতিটি স্ট্যান্সে নির্দিষ্ট পায়ের অবস্থান, হাঁটু বাঁকানো এবং ওজনের ভারসাম্যের নিয়ম রয়েছে।

## স্ট্যান্স রেফারেন্স তালিকা

| জাপানি নাম | নাম (English) | বিবরণ |
|---|---|---|
| [Heisoku Dachi](/prospectus/stances/heisoku) | Closed Foot Stance | আঙুল ও গোড়ালি একসাথে যুক্ত — প্রস্তুত বা অ্যাটেনশন স্ট্যান্স। |
| [Musubi Dachi](/prospectus/stances/musubi) | Open Foot Stance | গোড়ালি একসাথে এবং আঙুল বাইরে খোলা — "V" আকৃতির স্ট্যান্স। |
| [Heiko Dachi](/prospectus/stances/heiko) | Parallel Stance | পা সমান্তরাল (হিপের সমপরিমাণ চওড়া)। |
| [Hachiji Dachi](/prospectus/stances/hachiji) | Natural Stance | পা কাঁধের চওড়া, আঙুল ৪৫ ডিগ্রি বাইরের দিকে নির্দেশিত। |
| [Uchi-Hachiji Dachi](/prospectus/stances/uchi-hachiji) | Inverted Natural Stance | পা কাঁধের চওড়া, আঙুল ৪৫ ডিগ্রি ভেতরের দিকে নির্দেশিত (Niafanchi Dachi)। |
| [Shiko Dachi](/prospectus/stances/shiko) | Straddle Stance | দুই পা চওড়া করে হাঁটু বাঁকানো — "সুমো" স্ট্যান্স। |
| [Moto Dachi](/prospectus/stances/moto) | Basic Forward Stance | সামনের হাঁটু সামান্য বাঁকানো, সংক্ষিপ্ত ফরোয়ার্ড স্ট্যান্স। |
| [Zenkutsu Dachi](/prospectus/stances/zenkutsu) | Long Forward Stance | সামনের হাঁটু গভীর বাঁকানো, দীর্ঘ ফরোয়ার্ড স্ট্যান্স। |
| [Nekoashi Dachi](/prospectus/stances/nekoashi) | Cat Foot Stance | "বিড়ালের পায়ের" স্ট্যান্স — ওজনের সিংহভাগ পেছনের পায়ে। |
| [Sanchin Dachi](/prospectus/stances/sanchin) | Hourglass Stance | ভেতরের টেনশন স্ট্যান্স ("আওয়ারগ্লাস" স্ট্যান্স)। |
| [Kokutsu Dachi](/prospectus/stances/kokutsu) | Back Stance | "পেছনের দিকে ঝুঁকে থাকা" ব্যাক স্ট্যান্স। |
| [Renoji Dachi](/prospectus/stances/renoji) | L-Shape Stance | ইংরেজি "L" অক্ষরের মতো পায়ের অবস্থান। |
| [Tee-Ji Dachi](/prospectus/stances/tee-ji) | T-Shape Stance | উল্টো "T" অক্ষরের মতো পায়ের অবস্থান। |
| [Kosa Dachi](/prospectus/stances/kosa) | Hooked Leg Stance | "ক্রস লেগ" বা ক্রস করা পায়ের স্ট্যান্স। |
| [Sagiashi Dachi](/prospectus/stances/sagiashi) | Heron Foot Stance | "এক পায়ে দাঁড়ানো" বা সারস পাখির মতো স্ট্যান্স। |
| [Ukiashi Dachi](/prospectus/stances/ukiashi) | Floating Foot Stance | Nekoashi-এর মতো হলেও কিছুটা সোজা এবং হালকা ভাসমান পায়ের স্ট্যান্স। |
