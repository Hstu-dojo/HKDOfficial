# Blocking Techniques — Uke-Waza

**受け技** — The art of receiving and neutralising an attack.

In Shito-Ryu, blocking is not merely passive deflection. Effective blocks create the conditions for counter-attack, and in many cases *are* the counter-attack (as in [Tsuki Uke](/prospectus/blocks/tsuki-uke) — the simultaneous punch-block). Blocks are classified by level (gedan/chudan/jodan), direction, and hand formation.

---

## Fundamental Blocks

| Japanese Name | English Name | Description |
|---|---|---|
| [Gedan Barai Uke (Hari Uke)](/prospectus/blocks/gedan-barai) | Low Sweep Block | Low-level, downward sweeping block — deflects attacks to the groin and lower body. |
| [Yoko Uke (Soto Uke)](/prospectus/blocks/yoko-uke) | Outside Block | Block from inside (centre of body) toward outside — deflects mid-level attacks. |
| [Yoko Uchi (Uchi Uke)](/prospectus/blocks/yoko-uchi) | Inside Block | Block from outside toward inside (centre of body) — redirects mid-level strikes inward. |
| [Age Uke](/prospectus/blocks/age-uke) | Rising Block | Rising, upper-level block — deflects attacks to the head and face upward. |
| Yoko Bari Uke | Side Sweep Block | Side, sweeping block — lateral deflection. |
| Uchi Otoshi Uke | Inside Drop Block | Circular, inside dropping (downward pushing) block. |

---

## Simultaneous & Augmented Blocks

| Japanese Name | English Name | Description |
|---|---|---|
| [Tsuki Uke](/prospectus/blocks/tsuki-uke) | Punch Block | Simultaneous punching (forearm) block — the counter-attack IS the block. |
| Te Kubi Sasae Uke | Supported Wrist Block | Augmented (supported) wrist block — one hand supports the blocking hand at the wrist. |
| Sukui Uke | Scoop Block | Scoop block — scooping motion to intercept low attacks. |
| Hijisasae Uke | Elbow Block | Augmented (inside-middle) elbow block. |

---

## Open-Hand Blocks

| Japanese Name | English Name | Description |
|---|---|---|
| Shuto Uke | Knife-Hand Block | "Knife-hand" block — using the outer edge of the open hand. |
| Nagashi Uke | Flowing Block | Cross-body open-hand flowing/sweeping block. |
| Shiuko Uke (Haishu Uke) | Back-Hand Block | Open-hand, back-hand block. |
| Shotei Uke (Teisho) | Palm-Heel Block | Palm-heel block — using the heel of the palm. |

---

## Cross & Pressing Blocks

| Japanese Name | English Name | Description |
|---|---|---|
| Kosa Uke | X-Block | "X" block — wrists crossed to catch and trap attacks. |
| Osae Uke | Pressing Block | Pressing down block — deflects downward. |
| Kakewake Uke | Reverse-Wedge Block | Reverse-wedge block — both hands separate outward simultaneously. |

---

## Blocking Levels (Targets)

| Level | Japanese | Target Area |
|---|---|---|
| Upper | Jodan | Head, face, neck |
| Middle | Chudan | Chest, solar plexus, ribs |
| Lower | Gedan | Abdomen, groin, legs |
